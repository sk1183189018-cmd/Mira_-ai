🌟 About MIRA

What is MIRA?

MIRA is an advanced personal AI Assistant designed for Windows computers.

MIRA is not intended to be just a normal chatbot.

The goal of this project is to build a powerful AI assistant that can communicate naturally with the user, understand tasks, use AI models, remember useful information, assist with coding, manage files, help control the computer, research information from the web, analyze screenshots, and automate repetitive tasks.

MIRA is designed to become a personal digital assistant and intelligent computer companion.

---

🎯 Project Goal

The main goal of MIRA is to create a professional AI assistant that can help users with everyday computer tasks.

MIRA should eventually be able to:

- 💬 Communicate naturally

- 🧠 Use advanced AI models

- 🎨 Provide a professional user interface

🚀 Installation

Step 1 — Clone the Repository

git clone YOUR_REPOSITORY_URL

---

Step 2 — Open the Project

cd MIRA-AI-Assistant

---

Step 3 — Create a Virtual Environment

Windows:

python -m venv .venv

---

Step 4 — Activate the Virtual Environment

Windows:

.venv\Scripts\activate

---

Step 5 — Install Dependencies

pip install -r requirements.txt

---

🔑 Environment Configuration

The project includes:

.env.example

Create a new file called:

.env

Example:

OPENAI_API_KEY=your_real_api_key_here
MIRA_NAME=MIRA
MIRA_LANGUAGE=hinglish
MIRA_ENV=development
MIRA_DEBUG=true
MIRA_DATABASE_URL=sqlite:///data/mira.db

⚠️ Never upload your real ".env" file to GitHub.

python main.py
